Formación y Experiencia

En Fundación Kinal Perito en Informatica Diversificado

Inicios en la programación

Inicié mi formación en programación con el lenguaje Java a nivel introductorio y, hacia finales de ese año, adquirí conocimientos fundamentales de bases de datos relacionales utilizando MySQL.

Consolidación de herramientas y formación

Design Institute Durante este año me familiaricé con el uso de XAMPP, Apache Tomcat y Postman para la ejecución y prueba de APIs. Además, trabajé con JavaFX para el desarrollo de interfaces gráficas y utilicé Git como sistema de control de versiones y gestión de proyectos. Asimismo, completé procesos de certificación en Platzi, obteniendo los siguientes diplomas:

Java Básico, Java Programación Orientada a Objetos, Persistencia con Java, Java y SQL, SQL y MySQL

Primeros pasos en el desarrollo full stack

Me adentré en el ecosistema JavaScript, incorporando Node.js para el desarrollo backend, MongoDB como base de datos NoSQL y React para el frontend, consolidando así conocimientos clave de desarrollo web moderno. Adicionalmente, aprendí a desplegar proyectos en la nube utilizando MongoDB Atlas.

Experiencia en Practicas en Tribarl Worldwide Guatemala

Mi experiencia en Tribal Worldwide Guatemala, donde completé 400 horas de prácticas profesionales, fue altamente enriquecedora y me permitió fortalecer tanto habilidades técnicas como blandas. Desde los primeros días recibí una inducción al entorno de trabajo y acceso a herramientas como Clockify, correo corporativo, Jira y Discord, además de documentación interna como “Documentación HU & PR’s” e “Inducción Backend Devs”. Durante el proceso, profundicé en el uso de PHP y Laravel, participé en la incorporación a un proyecto con acceso a repositorios y configuré el entorno de desarrollo utilizando Ubuntu y Docker para ejecutar y gestionar los servicios necesarios. Trabajé realizando cambios en el proyecto, gestionando commits y pull requests para reflejar las actualizaciones en los repositorios, y asistí en dos ocasiones a las instalaciones (la modalidad principal fue virtual). Adicionalmente, reforcé mis conocimientos en algoritmos, resolví una evaluación técnica diseñada por mi encargado para medir la lógica de los practicantes e investigué sobre patrones de gestión de estado con el objetivo de contribuir a la mejora de la arquitectura del proyecto.
